# כיול סימולטור "אי האנרגיה"

כל המספרים נמצאים בקובץ `js/challenge/model.js`. בדקתי במחשב את כל התוכניות האפשריות בתוך התקציב, והרצתי כל אחת על שלושת ימי הבדיקה.

**תנאי "עומדת בכל התנאים":** בתוך 100 מטבעות (כולל דלק), ולכל היותר שעת חושך אחת בשלושת הימים (כמו "מצוין" במחוון).

## התוצאה

- **29 תוכניות** עומדות בכל התנאים, ב-**10 הרכבים שונים** של תחנות.
- **אף תוכנית לא הכי טובה בכל המדדים.** הזולה ביותר מעלה הרבה עשן, והנקייה ביותר יקרה יותר ויש בה שעת חושך.

## ארבע תוכניות לדוגמה

| תוכנית | עלות | שעות חושך (סוער / שקט / קיץ) | עשן | קוד |
| --- | --- | --- | --- | --- |
| 6 טורבינות ברכס + סכר | 95 | 0 / 1 / 0 | נקי | W600-H1111-S0-0000 |
| 3 טורבינות ברכס + סכר + קיטורית קטנה רק בערב | 94 | 0 / 0 / 0 | מעט | W300-H1111-S1-0001 |
| 2 טורבינות ברכס + סכר + קיטורית קטנה בוקר עד ערב | 84 | 0 / 0 / 0 | הרבה | W200-H1111-S1-0111 |
| סכר + קיטורית גדולה, בלי טורבינות | 91 | 0 / 0 / 0 | הרבה | W000-H1001-S2-0111 |

אפשר להדביק כל קוד בכפתור "טעינת תוכנית" בעמוד האתגר ולראות את התוצאה.

## מה לומדים מזה

- **הסכר נמצא בכל התוכניות שעובדות.** הוא שומר מים לשעות הערב בלי רוח, בדיוק כמו בתחנה 3.
- **בקיץ היבש מלאי הדלק קטן (16 שעות עבודה).** תחנה קיטורית שעובדת מהלילה נגמרת לפני הערב. צריך לתכנן מתי היא עובדת.
- **ביום השקט כמעט אין רוח.** תוכנית בלי קיטור צריכה הרבה טורבינות וסכר, ועדיין נשארת שעת חושך אחת.

## המספרים שכוילו

| מה | ערך |
| --- | --- |
| טורבינה ברכס, ברוח מלאה | 2.5 יחידות חשמל בשעה (בחוף 60%, בעמק 15%) |
| סכר, שער פתוח | עד 7 יחידות בשעה, רק מה שחסר. מאגר של 60 |
| מים בבוקר / תוספת בשעה | סוער 60 / 4 · שקט 46 / 1.5 · קיץ 20 / 0.3 |
| קיטורית קטנה / גדולה | 3 / 7 יחידות בשעה. דלק 3 / 7 מטבעות ליום. עשן 1 / 3 בשעה |
| דלק בקיץ היבש | 16 שעות עבודה |
| עשן | 0 = נקי, עד 36 = מעט, מעל = הרבה |

## שינוי אחד מהמסמך

במסמך כתוב "אפשר לקבוע באילו שעות פותחים את השער". בסימולטור קובעים לכל חלק ביום (לילה, בוקר, צהריים, ערב) אם השער פתוח, ואם התחנה הקיטורית עובדת. כשהשער פתוח יוצאים רק המים שחסרים באותה שעה. כך המים לא מתבזבזים כשהרוח כבר מספיקה, והתלמידים מתמקדים בשאלה החשובה: **מתי** לפתוח.

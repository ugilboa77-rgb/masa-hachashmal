# מילון, ממשק ומקורות

## מילון מושגים

כל מושג מופיע בעמוד המילון, וגם כחלונית קטנה כשלוחצים עליו בתוך טקסט.

| מושג | הסבר | תחנה |
| --- | --- | --- |
| אנרגיה | מה שמאפשר לדברים לזוז, להתחמם או להאיר. אי אפשר ליצור אותה מכלום, רק להפוך מסוג אחד לסוג אחר. | 1 |
| תחנת כוח | מקום שמייצרים בו חשמל בכמות גדולה ושולחים אותו לבתים. | 0 |
| קווי חשמל | חוטים עבים שמובילים חשמל מתחנת הכוח, לפעמים מרחק של עשרות קילומטרים. | 0 |
| מחולל | מכונה שהופכת סיבוב לחשמל. בתוכה מגנט וסליל. | 1 |
| מגנט | חפץ שמושך ברזל. כשהוא זז ליד חוט נחושת, נוצר בחוט חשמל. | 1 |
| סליל | חוט נחושת ארוך שמלופף הרבה פעמים, כמו קפיץ. | 1 |
| טורבינה | גלגל עם להבים או כפות. רוח, מים או קיטור מסובבים אותה, והיא מסובבת מחולל. | 2 |
| להבים | החלקים הארוכים של טורבינת רוח, שהרוח דוחפת. | 2 |
| בית מכונות | התא שבראש התורן של טורבינת רוח. נמצא בו המחולל. | 2 |
| סכר | קיר ענק שעוצר נהר ויוצר מאחוריו אגם. | 3 |
| מאגר | מקום שבו שומרים מים לשימוש מאוחר יותר. | 3 |
| תחנה שאובה | תחנה שמעלה מים למאגר גבוה כשיש חשמל מיותר, ומורידה אותם דרך טורבינה כשצריך חשמל. | 3 |
| קיטור | מים שהתחממו עד שהפכו לגז. הוא תופס הרבה מקום ודוחף בכוח. | 4 |
| דוד | מיכל ענק שבו מרתיחים מים בתחנה קיטורית. | 4 |
| דלק | חומר ששורפים כדי לקבל חום, כמו פחם או גז. אחרי שנשרף, אי אפשר להשתמש בו שוב. | 4 |
| זיהום אוויר | עשן וגזים שנכנסים לאוויר ופוגעים בבריאות של בני אדם ובסביבה. | 4 |

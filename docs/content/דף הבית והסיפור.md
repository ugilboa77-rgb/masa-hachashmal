# דף הבית ועולם הסיפור

## כותרת האתר

- **שם האתר:** מסע החשמל
- **שורה עליונה:** מדע וטכנולוגיה · כיתה ו׳
- **כותרת ראשית:** מסע החשמל
- **שורת משנה:** אי שלם נשאר בחושך. אתם המהנדסים שיחזירו לו את האור.

## פתיחה

**לחצתם על המתג והאור נדלק. אבל מאיפה הגיע החשמל?**

באי האלמוג אף אחד לא שאל את השאלה הזו, עד שהאור כבה. סערה השביתה את המחולל היחיד של האי. עכשיו התושבים צריכים מערכת חשמל חדשה, והם פנו אליכם.

במסע תעברו בחמש תחנות. בכל תחנה תגלו דרך אחרת לייצר חשמל. בסוף תתכננו לאי מערכת שלמה.

## מפת המסע

**כותרת משנה:** מפת המסע **כותרת:** חמש תחנות ואתגר אחד בסוף

| נקודה במפה | שני מילים מתחת לשם |
| --- | --- |
| 0. נקודת זינוק | האי כבה |
| 1. המחולל | סיבוב הופך לחשמל |
| 2. טורבינת רוח | רוח מסובבת |
| 3. תחנה הידרואלקטרית | מים מסובבים |
| 4. תחנה קיטורית | קיטור מסובב |
| 5. השוואה | ישיבת מועצה |
| אתגר | התוכנית שלכם |

תחנה שהושלמה מסומנת במפה בסמל ונורה דולקת. בכל תחנה שמסתיימת, עוד חלק של האי מתאיר.

## איך לומדים כאן

**כותרת משנה:** איך לומדים כאן **כותרת:** בכל תחנה ארבעה שלבים

| שלב | משפט |
| --- | --- |
| מגלים | קוראים, צופים ומנבאים מה יקרה. |
| מנסים | בודקים בהדמיה מה משנה את התוצאה. |
| חוקרים בידיים | עושים ניסוי אמיתי בשולחן הניסויים. |
| מדווחים למועצה | עונים על נקודת הביקורת ב-Classroom. |

**קצב אישי:** כל אחד מתקדם בקצב שלו. חלקים שמסומנים "אם יש זמן" הם למי שסיים את השאר. תקועים? נסו קודם את כפתור הרמז, ואז הפכו את כרטיס הרמזור.

## כפתורים בדף הבית

- כניסה ראשונה: **מתחילים את המסע**
- כניסה חוזרת: **המשיכו מאיפה שעצרתם**, ומתחתיו בקטן: תחנה {מספר}, {שם החלק}

## כרטיס הרמזור

כרטיס קבוע בפינת המסך. כל לחיצה מעבירה למצב הבא.

| מצב | סמל | טקסט |
| --- | --- | --- |
| ירוק | גלגל שיניים | אני עובד |
| צהוב | יד מורמת | תקוע, צריך עזרה |
| כחול | דגל | סיימתי תחנה |

כשהכרטיס במצב "צריך עזרה", הוא גדל ומופיעה מתחתיו השורה: המורה רואה אתכם. בינתיים נסו את כפתור הרמז.

# מסע החשמל

לומדה ללמידה עצמית לכיתה ו׳ בנושא הפקת חשמל בתחנות כוח.
אתר סטטי בעברית: HTML, CSS ו-JavaScript רגילים, בלי שרת ובלי שלב בנייה.
האתר לא שולח שום מידע לשום מקום. ההתקדמות של התלמיד נשמרת רק בדפדפן שלו.

---

## 1. איך מחליפים קישור או סרטון

כל הקישורים נמצאים בקובץ אחד: **`js/config.js`**. פותחים אותו בכל עורך טקסט (גם בפנקס רשימות).

### סרטון YouTube

מעתיקים רק את **המזהה** של הסרטון, בלי הכתובת המלאה:

| הכתובת ב-YouTube | המזהה |
| --- | --- |
| `https://www.youtube.com/watch?v=FUCkaXsqRP8` | `FUCkaXsqRP8` |
| `https://youtu.be/FUCkaXsqRP8` | `FUCkaXsqRP8` |

ומדביקים אותו בין המירכאות בשורה המתאימה:

```js
station1: {
  video1: "FUCkaXsqRP8",   // איך מחולל עובד
```

### טופס, משימה ב-Classroom או מסמך

מדביקים את **הכתובת המלאה** בין המירכאות:

```js
checkpoints: {
  station1: "https://forms.gle/....",   // נקודת ביקורת: המחולל
```

### כללים חשובים

- קישור שנשאר ריק (`""`) מופיע באתר ככפתור **"בקרוב"**, ולא ככפתור שבור.
- לא מוחקים מירכאות, ולא מוחקים את הפסיק שבסוף השורה.
- בעמוד המורה (`teacher.html`) יש רשימה שמראה אילו קישורים כבר הוגדרו ואילו חסרים.

### רשימת הקישורים

| מפתח ב-config.js | מה זה |
| --- | --- |
| `videos.station1.video1` / `video2` | תחנה 1: איך מחולל עובד / מחולל אמיתי בתחנת כוח |
| `videos.station2.video1` / `video2` | תחנה 2: איך עובדת טורבינת רוח / בתוך בית המכונות |
| `videos.station3.video1` | תחנה 3: איך עובדת תחנה הידרואלקטרית |
| `videos.station4.video1` | תחנה 4: איך עובדת תחנת כוח קיטורית |
| `checkpoints.station1` … `station3` | נקודות הביקורת של תחנות 1–3 |
| `checkpoints.stations4and5` | נקודת הביקורת המשותפת לתחנות 4 ו-5 |
| `classroom` | הכיתה ב-Classroom |
| `journalDoc` | משימת "יומן מהנדס" ב-Classroom (הכפתור "פתיחת היומן") |
| `challengeForm` | טופס הגשת האתגר |

## 2. איך מתקנים טקסט

כל עמוד הוא קובץ אחד, והטקסטים כתובים בתוכו כמו שהם מופיעים באתר.

| מה רוצים לתקן | איפה |
| --- | --- |
| דף הבית | `index.html`, והמפה והכרטיסים ב-`js/home.js` |
| תחנה 0–5 | `station-0.html` … `station-5.html` |
| אתגר הסיכום | `challenge.html`. ההודעות והמשפטים של נעמה בתוך ההדמיה: `js/challenge/simulator.js` |
| מילון המושגים | `js/glossary-data.js` |
| עמוד המורה | `teacher.html` |
| טקסט בתוך הדמיה (תוויות, מסך פתיחה) | `js/sims/` – קובץ לכל תחנה |

**איך מוצאים טקסט:** בעורך הטקסט לוחצים Ctrl+F ומחפשים כמה מילים מתוך המשפט.
מחליפים רק את המילים, ולא נוגעים בסימנים `<` `>` שמסביב.

**דפי ההדפסה** נבנים מתוך עמודי התחנות, כך שתיקון בתחנה מופיע גם בדף ההדפסה.

---

## 3. איך רואים את האתר במחשב

האתר צריך "שרת מקומי" קטן (כי הוא בנוי ממודולים). יש אחד מוכן בתיקייה `tools`:

1. לחיצה ימנית על `tools/serve.ps1` ← "Run with PowerShell".
2. פותחים בדפדפן את הכתובת `http://localhost:8000`

במחשב שיש בו Python אפשר גם: `python -m http.server 8000` מתוך תיקיית הפרויקט.

---

## 4. איך מפרסמים (GitHub Pages)

1. מעלים את כל התיקייה למאגר ב-GitHub (חוץ מתיקיית `docs`, שאפשר להשאיר – היא לא חלק מהאתר).
2. במאגר: **Settings ← Pages ← Source: Deploy from a branch**, בוחרים את הענף הראשי ואת התיקייה `/ (root)`.
3. אחרי דקה-שתיים האתר זמין בכתובת שמופיעה שם.
4. כל שינוי שמעלים ל-GitHub מתעדכן באתר תוך כמה דקות.

**לפני שמשתמשים בכיתה:** לפתוח את הכתובת ממחשב של בית הספר ובחשבון תלמיד, ולבדוק שהאתר נפתח, שסרטון מתנגן ושטופס מזהה את התלמיד.

## 6. הסימולטור של האתגר

כל המספרים (מחירים, ימי הבדיקה, כמה מייצרת כל תחנה) נמצאים ב-**`js/challenge/model.js`**.
הכיול מוסבר ב-**`docs/calibration.md`**: יש 29 תוכניות שונות שעומדות בכל התנאים, ואין תוכנית אחת שהכי טובה בכל המדדים.
אם משנים מספר, כדאי לבדוק שוב שהתוכניות לדוגמה בעמוד המורה עדיין עובדות.

```
index.html, station-0…5.html, challenge.html, glossary.html, journal.html, teacher.html, print.html

css/base.css        עיצוב כללי וכל הרכיבים
css/print.css       הדפסה
js/config.js        כל הקישורים
js/site.js          רשימת התחנות והשמות שלהן
js/storage.js       שמירה בדפדפן (עובד גם כשהשמירה חסומה)
js/progress.js      התקדמות, יומן המהנדס, רמזים
js/ui/              רכיבים: תפריט, רמזור, רמזים, נעילה, העתקה, שעון עצר, מיון ועוד
js/sims/            הדמיה לכל תחנה, ומנוע משותף (engine.js)
js/challenge/       סימולטור האתגר: model.js (חישוב) ו-simulator.js (מסך)
js/station-N.js     החיבורים של כל תחנה
assets/fonts        הגופנים Rubik ו-Assistant (שמורים בתוך האתר)
assets/images       תמונות וסמלים
docs/               מסמך הדרישות, התוכן והכיול (לא חלק מהאתר)
tools/serve.ps1     שרת מקומי לתצוגה במחשב
```
